# 首都圈地铁助手 MVP

这是一个原生微信小程序第一版，目标是先跑通：

- 中文/韩文站名搜索
- 出发站和到达站选择
- 基于站点图的路线查询
- GPS 定位最近地铁站
- 为实时到站接口预留数据层

## 如何打开

1. 安装微信开发者工具。
2. 导入 `work/metro-miniapp` 文件夹。
3. AppID 暂时使用 `touristappid` 体验；以后替换成你自己的小程序 AppID。
4. 点击编译，在模拟器中测试。

## 当前限制

本 MVP 内置的是一组首都圈主要站点和演示线路关系，用来先验证产品交互和算法。要覆盖完整首都圈，需要把完整站点、相邻站关系、换乘关系、首末班车时刻表导入 `data/metro.js` 或改为云端数据库。

实时到站数据暂未硬编码到小程序中。正式接入时，应由云函数调用首尔开放数据等官方接口，再把密钥放在云端，不能放进前端代码。
